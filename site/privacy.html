プライバシーポリシー

対象: PowerPoint アドイン「Mermaid on PowerPoint」

集める情報

このアドインは、個人情報や利用状況を集めません。アカウント登録もありません。

プレゼンテーションの内容

  • アドインは、図を作るために開いているプレゼンテーション（スライドのノートとテーマの色）を読み取ります
  • 図の生成はすべてお使いの PC の中（PowerPoint のアドイン画面）で行い、プレゼンテーションの内容をこのサイトやほかのサーバーに送りません
  • 生成した図と、その元になった Mermaid のコード、テーマの設定は、プレゼンテーションのファイルの中に保存されます

通信

アドインを開くとき、アドインのプログラムをこのサイト（GitHub Pages）から、Office の共通ライブラリ（Office.js）を Microsoft のサーバーから読み込みます。これらのサーバーが通常のアクセス記録（IP アドレスなど）を残すことがあります。詳しくは GitHub のプライバシーステートメントと Microsoft のプライバシーに関する声明をご覧ください。

変更

内容を変えるときは、このページを更新します。
