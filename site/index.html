Mermaid on PowerPoint

スライドのノートに書いた Mermaid 記法から図を作って、スライドに入れる PowerPoint アドインです。ノートを書き換えてボタンを押すと、図が同じ位置のまま更新されます。

非公式のアドインです。Mermaid および Mermaid Chart 社とは関係ありません。

できること

  • ノートの ```mermaid ブロックから図（SVG）を生成
  • ノートを書き換えたら、位置と横幅を保ったまま置き換え。全スライドの一括更新
  • テーマ（モダン・モノトーン・ネイビー・テンプレートの色・カスタムなど）
  • 図の元になったコードは pptx の中に残るので、ファイル 1 つで受け渡しできます

動作環境

PowerPoint for Windows（Microsoft 365）。Mac 版・Web 版では動作を確認していません。

インストール（Windows）

アドインのファイルはこのサイトから読み込まれます。PC に入れるのは、アドインの場所を書いた設定ファイル（manifest.xml）だけです。

  1. install.ps1 をダウンロードします
  2. ダウンロードしたファイルを右クリック →「PowerShell で実行」します。途中で管理者の確認が出たら「はい」を選びます（manifest.xml を置くフォルダーを共有するためです）
  3. PowerPoint を開き直し、ホーム → アドイン → 詳細（または「その他のアドイン」）→ 共有フォルダー から「Mermaid on PowerPoint」を選んで「追加」します

スクリプトが行うのは次の 3 つだけです。中身はテキストエディターで確認できます。

  • %LOCALAPPDATA%\MermaidOnPptx\manifest に manifest.xml を保存する
  • そのフォルダーを自分だけが読める共有フォルダーにする
  • PowerPoint の「信頼できるアドイン カタログ」にそのフォルダーを登録する（Microsoft の共有フォルダーからの読み込み手順と同じ設定です）

手で設定する場合は、上のリンク先の手順で manifest.xml を共有フォルダーに置いてください。会社の PC では、管理者の設定でアドインが使えないことがあります。

アンインストール

PowerShell で install.ps1 -Uninstall を実行すると、登録・共有・フォルダーを取り消します。

使い方

ノートに次のように書いて、ホームタブの「図を生成」を押します。パネルの「サンプル」からコピーすることもできます。

```mermaid id=login
sequenceDiagram
  User->>App: ログイン
  App-->>User: OK
```

詳しい使い方・制限事項・ソースコードは GitHub にあります。
