Mermaid on PowerPoint

スライドのノートに書いた Mermaid 記法から図を作って、スライドに入れる PowerPoint アドインです。ノートを書き換えてボタンを押すと、図が同じ位置のまま更新されます。

現在は作者が自分で使いながら試している段階（ドッグフーディング中）です。予告なく仕様の変更や配信の停止をすることがあります。MIT ライセンスのとおり無保証で、利用によって生じた問題には責任を負えません。大切な資料はバックアップを取ってからお使いください。

非公式のアドインです。Mermaid および Mermaid Chart 社とは関係ありません。

どんなアドインか、入れ方と使い方は 利用ガイド（guide.pptx） にまとめています。ガイドの図もこのアドインで作っているので、ノートを開くと書き方の見本になります。 内容を読んで、無保証でもよければお試しください。

できること

  • ノートの ```mermaid ブロックから図（SVG）を生成
  • ノートを書き換えたら、位置と横幅を保ったまま置き換え。全スライドの一括更新
  • テーマ（モダン・モノトーン・ネイビー・テンプレートの色・カスタムなど）
  • 図の元になったコードは pptx の中に残るので、ファイル 1 つで受け渡しできます

動作環境

PowerPoint for Windows（Microsoft 365）。Mac 版・Web 版では動作を確認していません。

インストール（Windows）

アドインのファイルはこのサイトから読み込まれます。PC に置くのは、アドインの場所を書いた設定ファイル（manifest.xml）だけです。 Microsoft の共有フォルダーからの読み込み手順に沿って、手で設定します。

1. manifest.xml を共有フォルダーに置く

  1. manifest.xml を置くフォルダーを作ります（例: C:\Users\<ユーザー名>\MermaidOnPptx）。manifest.xml をダウンロードして、そこに入れます
  2. フォルダーを右クリック →プロパティ →共有タブ →共有を選び、自分を追加して共有を選びます
  3. 表示されたネットワーク パス（\\PC名\MermaidOnPptx のような形）を控えて、完了を選びます

2. PowerPoint に共有フォルダーを登録する

  1. PowerPoint でファイル → オプション → トラスト センター → トラスト センターの設定 → 信頼されているアドイン カタログを開きます（版によっては「セキュリティ センター」という名前です）
  2. カタログの URL に控えたネットワーク パスを入れてカタログの追加を選び、メニューに表示するにチェックを入れてOKを選びます
  3. PowerPoint を閉じて開き直します

3. アドインを追加する

  1. ホーム → アドイン → 詳細設定（または「その他のアドイン」）→共有フォルダーから「Mermaid on PowerPoint」を選んで追加します

所属する組織のポリシーなどによっては、アドインが使えない場合があります。

スクリプトでまとめて設定する場合

手順 1・2 は install.ps1 でもまとめて行えます。中身はテキストエディターで確認できます（manifest.xml を %LOCALAPPDATA%\MermaidOnPptx\manifest に保存し、そのフォルダーを自分だけが読める共有にして、信頼されているアドイン カタログに登録します）。 ファイルを右クリック →「PowerShell で実行」するか、PowerShell で powershell -ExecutionPolicy Bypass -File install.ps1 を実行します。共有を作るときだけ管理者の確認が出ます。

アンインストール

信頼されているアドイン カタログの登録とフォルダーの共有を外し、PowerPoint を開き直します。 スクリプトで設定した場合は install.ps1 -Uninstall で取り消せます。

使い方

ノートに次のように書いて、ホームタブの「図を生成」を押します。パネルの「サンプル」からコピーすることもできます。

```mermaid id=login
sequenceDiagram
  User->>App: ログイン
  App-->>User: OK
```

詳しい使い方・制限事項・ソースコードは GitHub にあります。
