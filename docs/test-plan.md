# 手動テスト記入表

リリース前に Windows 版 PowerPoint で実施し、結果欄に OK / NG とメモを書きます。
◎は必須（すべて OK でリリース）、○は任意（NG なら README の制限事項に書けばリリース可）です。

- 実施日:
- PowerPoint のバージョン（ファイル → アカウント → PowerPoint のバージョン情報）:
- アドインのバージョン / 開発版か公開版か:
- PC（CPU・メモリ）:

テスト用 pptx は `python3 test/fixtures/make_test_decks.py` で作ります（ノートだけ入った状態）。

## E. PowerPoint 以外での表示

`compat-samples.pptx` を開き、テーマを選んで「全スライドを更新」して保存します。modern / mono / navy / default の 4 テーマで 1 ファイルずつ作り、それぞれを次のアプリで開きます。

見るところ: 色・文字・矢印が PowerPoint for Windows と同じか。真っ黒や色抜けがあれば、どの図の種類かを書きます。
自動の描画チェック（`npm run test:render`）でも、色が CSS だけで付いている図形の数を出しています（2026-10-29 時点で flowchart・ER・mindmap・state に多い）。
